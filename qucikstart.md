# Quick start



- Download tailwind from [GitHub](https://github.com/tailwindlabs/tailwindcss):  `
tailwindcss-linux-x64 ` and  `tailwindcss-windows-x64.exe `. 


- Rename  `tailwindcss-windows-x64.exe ` to `tw.exe`.


- Dump your markdown folder into the`content/input_markdown/` folder (for best results, use the correct YAML format stated in readme.md).


- (skip this if you already built the binary):  On Linux, go to `eleventy_binary/` and run `compile.sh`.

- Go to `site_settings.json` and adjust what you want your page to be named and so on.

- Run the `encyclopedia-linux-x64`/`encyclopedia-win-x64.exe` file.

Read the readme.md for more details.
